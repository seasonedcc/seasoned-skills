A task is not done if it added or changed an app capability without extending the machine surface to match, held to the committed parity standard ({{parity-standard}}) by outcome fitness, never by endpoint existence. Every tool wraps a business function through the same layer the product uses; a tool may stand outside that rule only by criterion — a pure context projection, or a transport-only primitive — and every excepted tool is listed in the exception register ({{exception-register}}) with a one-line rationale. The parity check reads the register, so an unregistered exception fails the gate; never satisfy the check by parking a genuine capability as pending or dressing it up as an exemption.
