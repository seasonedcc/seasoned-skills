A task is not done if it changes a user-facing flow without a spec covering the changed behavior — a new spec, or an existing one updated to assert it — and without every route the flow touches reaching the coverage gate as covered. A new surface and the spec that reaches it land in the same change. The coverage register ({{coverage-register}}) is the shrink-only list of unreached surfaces: it only ever shrinks, and once empty it is held empty forever. A surface that genuinely cannot be reached by a spec is excused instead, in {{excused-surfaces}}, which admits an entry only with a one-line written rationale — and "no spec yet" is never a rationale. Load the `testing` skill for the conventions.
