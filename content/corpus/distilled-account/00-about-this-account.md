# About this account

This folder stands in for _Demand-Side Sales 101_ by Bob Moesta with Greg Engle.
The book is commercial, so the workflow never downloads or redistributes it.
What lives here instead is a distilled account: the frameworks the shaping
skill leans on, taught in our own words, deep enough that every citation the
skill makes into this collection resolves to a real explanation.

Two things this account is not:

- **It is not the book.** No sentence here is the book's, and none is anywhere
  else in the package either: the shaping skill cites this collection in its
  own words, and this account teaches the ideas behind those citations.
- **It is not a summary of the whole book.** It covers exactly the ground the
  skill cites — the frameworks chapter — and nothing more.

For verbatim study, get the real book. If you own a copy compiled to this
corpus's shape — a folder of numbered markdown chapters with images — run
`seasoned-skills corpus --book <path>` and the vendoring script replaces this
account with the actual chapters on your machine. The built corpus lives only
on your machine either way; it is never committed.
