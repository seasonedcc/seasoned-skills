This repository merges pull requests with a merge commit and keeps branch history linear, so a branch syncs with its base by rebasing onto it — a pushed branch included, under the discipline that makes rewriting pushed history safe. Run the pre-rebase conflict-surface check first. After the rebase, verify patch identity (`git range-diff <old-base>..<old-head> main..HEAD`): every commit accounted for, no content silently changed by the rewrite. Then reconcile everything that referenced the old commits — push with `--force-with-lease`, and bring every checkout, worktree, and open pull request that held the branch onto the new history.
